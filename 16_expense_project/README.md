# 💰 Expense Tracker

A simple and user-friendly Expense Tracker application built using React. This project helps users manage their income and expenses, track transactions, and calculate their total credit, debit, and balance.

## ✨ Features

- Add new income and expense transactions.
- View all transactions in a table.
- Edit existing transactions.
- Delete transactions.
- Search transactions by title.
- Filter transactions by category.
- Filter transactions by type (Credit or Debit).
- Calculate total Credit, Debit, and Balance.
- Manage shared data using React Context API.
- Responsive UI using React Bootstrap.

## 🛠️ Technologies Used

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/charmeepaneliya/React-Frontend.git
```

### 2. Navigate to the Project Folder

```bash
cd React-Frontend/16_expense_project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.

## 🧮 Expense Calculation

- **Credit:** Total amount of all credit transactions.
- **Debit:** Total amount of all debit transactions.
- **Balance:** Total Credit − Total Debit.
