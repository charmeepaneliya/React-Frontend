# 📝 React CRUD Todo List

A simple and responsive **Todo List application** built with **React.js** and **React Bootstrap**.

This project demonstrates the basic **CRUD operations** — Create, Read, Update, and Delete — along with task completion status management.

## 🚀 Live Demo

🔗 **Live Demo:** https://react-frontend-omega-one.vercel.app/

## 📂 GitHub Repository

🔗 **GitHub:** `https://github.com/charmeepaneliya/React-Frontend`

---

## ✨ Features

* ➕ Add new tasks
* 📋 Display all tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* ⏳ Show pending tasks
* 📊 Display total, completed, and pending task counts
* 📱 Responsive design
* 🎨 Styled using React Bootstrap
* ⚡ Built with React.js and Vite

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/charmeepaneliya/React-Frontend.git
```

### 2. Go to the project folder

```bash
cd React-Frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.

---

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
